# Data Accessibility Statement

This project uses the General Social Survey (GSS) Public Use Microdata.
Raw data are **not** redistributed in this repository.

**Where to obtain data:** https://gss.norc.org/get-the-data  
**Years used:** [fill in, e.g., 2018–2022]  
**Key variables:** harmgood, degree/educ, age, sex, race, relig/religiosity, partyid, year, [weight variable]  

**To replicate:**
1. Download the same GSS years from the official source.
2. Place the files under `data/` on your local machine.
3. Run the scripts in the order listed in `README.md`.
4. Outputs will be created in `outputs/`.
